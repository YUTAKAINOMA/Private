# 🌲 EnglishForest

短い英語の物語を、**英語の本文**と**日本語の要約**の両方で読める学習用サイトです。
どちらもブラウザの読み上げ機能で音声再生でき、読み上げ中の文がハイライトされるので、耳と目の両方でストーリーを追えます。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 日本語要約の音声再生 | 要約のすぐ上に再生／一時停止／停止ボタン。日本語音声（`ja-JP`）で読み上げ |
| 英語本文の音声再生 | 同じ操作で英語音声（`en-US`）で読み上げ |
| 速度調整 | 0.5× 〜 2.0× のスライダー。再生中に変えても即座に反映され、設定は次回も保持されます（日本語・英語で別々に記憶） |
| 読み上げ中のハイライト | 読み上げ中の文に色が付き、画面外なら自動でスクロール |
| 文をクリックして頭出し | 任意の文をクリック（またはキーボードで Enter / Space）すると、そこから読み上げ開始 |

## 使い方

`index.html` をブラウザで開くだけで動きます。ビルド作業もサーバーも不要です。

ローカルサーバー経由で見たい場合は、次のどちらかを実行して <http://localhost:8000> を開いてください。

```bash
python3 -m http.server 8000
# または
npx http-server -p 8000
```

GitHub Pages に公開する場合は、リポジトリの Settings → Pages で公開したいブランチのルート (`/`) を指定すればそのまま動作します。

## ファイル構成

```
index.html              画面の骨組み
assets/css/style.css    スタイル（ライト／ダークモード対応）
assets/js/speech.js     読み上げエンジン（Web Speech API のラッパー）
assets/js/player.js     再生／停止・速度スライダーのUI部品
assets/js/app.js        物語一覧・物語ページの描画とハイライト連動
data/stories.js         物語データ（英語本文・日本語要約・単語メモ）
```

すべて素の JavaScript（ES5 相当）で書かれており、外部ライブラリは使っていません。
ES モジュールを使っていないため、`file://` で直接開いても CORS で止まりません。

## 物語を追加する

`data/stories.js` の配列に 1 件足すだけです。

```js
{
  id: 'my-story',              // URL に使われます（#/story/my-story）
  title: 'My Story',
  titleJa: 'わたしの物語',
  level: 'A2',                 // A1〜C1 など、目安のレベル
  minutes: 3,                  // 読了目安（分）
  tags: ['やさしい'],
  body: '英語の本文。\n空行ではなく改行で段落を分けます。',
  summaryJa: '日本語の要約。\n同じく改行で段落を分けます。',
  vocab: [ { word: 'fog', ja: '霧' } ]   // 省略可
}
```

読み上げは文の区切りで分割されるため、**英語は `.` `!` `?`、日本語は `。` `！` `？` で必ず文を終える**ようにしてください。ハイライトの単位もこの区切りになります。

## 音声について

音声は OS とブラウザに内蔵された読み上げ機能（Web Speech API の `SpeechSynthesis`）を使っています。音声ファイルを配信しているわけではないので、追加の通信量もサーバーも必要ありません。

そのため、聞こえ方は端末によって変わります。

- **日本語音声が入っていない端末**では、その旨のメッセージを表示します（OS の音声設定に日本語を追加すると読み上げられます）
- **iPhone / iPad** では、画面のボタンを押して再生を開始する必要があります（自動再生は OS 側で禁止されています）
- **Android の Chrome** では一時停止が停止として扱われる場合があります
- Web Speech API に対応していないブラウザでは、コントロールの代わりに案内文を表示します（本文と要約はそのまま読めます）

## 動作確認済み

Chromium (Playwright) で、要約・本文それぞれの再生／一時停止／停止、速度変更の即時反映、ハイライト連動、文クリックでの頭出し、ページ遷移時の停止、音声が無い場合のフォールバック表示を確認しています。
